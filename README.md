# Agent_Justy 🐦🤖  

**Agent_Justy** is a smart and engaging Twitter bot designed to brighten timelines! It posts:  
- 🎉 **Daily Shoutouts**: Highlights top users and traders fetched from an API.  
- ✨ **Random Quotes**: Shares inspiring and entertaining quotes generated by **Meta's LLaMA 3 LLM**, integrated using by groq-sdk**.

![Justy](https://github.com/user-attachments/assets/9d2ac015-42d1-4203-b323-257b479aae8e)

## Features 🚀  
- **Daily Shoutouts**:  
  - 🎲 *Lucky Winner*: Celebrates the luckiest bettor of the day.  
  - 💰 *High Roller*: Highlights the top bettor.  
  - 📈 *Top Gainer*: Recognizes the most profitable trader.  

- **Random Quotes**:  
  - Posts engaging and creative quotes powered by **llama-3.3-70b-versatile LLM** through the lightweight and efficient cloud by **groq-sdk**.  

## How It Works 🛠️  
1. **API Integration**: Fetches daily stats for shoutouts.  
2. **llama-3.3-70b-versatile LLM with groq-sdk**: Generates dynamic, creative, and original quotes.  
3. **Twitter API**: Posts updates directly to Twitter on a scheduled basis.  

## Tech Stack ⚙️  
- **Node.js**: Backend logic.  
- **llama-3.3-70b-versatile**: For AI-generated quotes.  
- **groq-sdk**: Lightweight integration for Meta's llama-3.3-70b-versatile.  
- **Twitter API**: For posting tweets.  
- **GitHub Actions**: Automates the posting schedule.

## Setup and Deployment (Server Branch) 🔧  
1. Clone the repository:  
   ```bash
   git clone https://github.com/TSRohit99/Agent_Justy.git
   cd Agent_Justy
   ```
2. Install dependencies:
```bash
npm install
```
3. Run Locally at PORT:3000
```bash
npm run dev
```
